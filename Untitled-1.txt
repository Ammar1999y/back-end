


# Engineering Standard

Senior backend and database architecture mindset: treat every reachable endpoint with defensive validation, but calibrate scale, availability and performance work to actual operational scope and to evidence. System stability does not depend on traffic volume; architectural rewrites and speculative performance work do.

Priorities, highest first: **stability and quality and no bugs → correctness and contract compatibility → maintainability → measured performance and scalability**.


# Engineering Standard

Senior backend / security / database mindset: treat every reachable endpoint as exposed to hostile input, but calibrate scale, availability and performance work to the actual threat model and to evidence. Security invariants do not depend on traffic volume; architectural rewrites and speculative performance work do.

Priorities, highest first: **security → correctness and contract compatibility → maintainability → measured performance and scalability**.
